# 休暇申請

**いつ使うか:** 有給休暇、無給休暇、遅刻・早退、リモートワーク、慶弔休暇、その他の欠勤時。

## 申請を作成する

**手順**

1. **勤怠・休暇** → **休暇申請**。
2. **申請を作成** → **休暇種別**を選択（年次有給、病気休暇、無給休暇、遅刻、早退、リモートワークなど、会社の規定による）。
3. 日付・時間を選択します。
4. 理由を入力します（任意ですが、承認者の判断に役立ちます）。
5. **承認者**を選択します(通常は直属の上司)。
6. **慶弔**の場合: **慶弔種別**を選び、上限日数を超えないようにします。
7. 送信 → 承認待ち。

## 残り休暇の表示

利用可能な休暇は申請フォームの上部に、次のいずれかの形式で表示されます。

- **日数表示:** 例 `残り 5.5 日`(1営業日 = 1日)
- **分表示:** 例 `残り 440 分`(1営業日 = 480分 = 8時間、半日 = 240分)

表示形式(日 ↔ 分)は、残数の横のボタンで切り替えられます。

**例:** 残り480分のうち240分(4時間)取得 → 残り240分。残り10日のうち1日取得 → 残り9日。

## 遅刻・早退の申請

- **遅刻:** 始業時刻より遅く出社した場合、遅れた分数を申請します。例: 始業8:00、出社8:30 → **30分**の遅刻申請。
- **早退:** 終業時刻より早く退社する場合、早く帰る分数を申請します。例: 終業17:00、退社16:30 → **30分**の早退申請。

### 残り休暇が足りない場合:「無給」の選択

遅刻・早退の申請に対して休暇残数が不足している場合、次の選択肢が表示されます。

1. **申請を取りやめる** — 送信しない。
2. **無給として計上する** — その分数は休暇残数から差し引かれませんが、**給与は支払われません**。申請には赤い**無給**バッジが表示されます。

注意: 無給にできるのは**遅刻・早退の申請のみ**です。終日の休暇申請は無給にできません。

## 事前休暇申請(日付未定)

将来休暇が必要と分かっているものの、具体的な日付が未定の場合に使用します(例: 来月分として3日先に確保)。

1. 申請を作成 → 休暇種別を選択 → **事前休暇**を選択(利用可能な場合)。
2. 必要な時間を入力: **日数**(`5日`)、**時間**(`40時間`)、**分**(`2400分`)のいずれか。
3. 承認者を選択し、理由を入力 → 送信。
4. 承認後、日付が決まったら、承認済みの事前休暇を使って改めて申請します。

## 申請の確認

- 一覧には**状態**(承認待ち / 承認 / 却下)、種別、期間、理由が表示されます。
- **承認待ち**の申請は、通常**編集**または**削除(取消)**が可能です。承認後は編集・削除できません。

**期待される結果:** 申請が一覧に表示され、承認者が処理できます。

**困ったとき**

- 送信できない → **休暇種別**、**承認者**、**開始日・終了日**(必須項目)を確認してください。
- 残り休暇が不足と表示される → 取得時間を減らす、無給を選択する(遅刻・早退のみ)、または人事にご相談ください。
- 慶弔の日数が上限超過 → 種別を変更するか期間を短縮してください。
- 遅刻・早退の申請が却下された → 上司または人事に理由を確認し、必要に応じて説明を補足して再申請してください。

**ヒント:** 早めに申請する。理由を明確に書く。日付を選ぶ前にカレンダーの祝日と残り休暇を確認する。休暇の予定はチームに事前に共有する。
