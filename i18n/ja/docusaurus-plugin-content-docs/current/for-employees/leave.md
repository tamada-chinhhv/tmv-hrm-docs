# 休暇申請

**いつ使うか:** 有給、無給、遅刻・早退、リモート、慶弔休暇など。

**手順 — 作成**

1. **勤怠・休暇** → **休暇申請**。
2. 申請作成 → 種別・期間・理由を選択。
3. **慶弔（hiếu hỷ）**: **慶弔種別** を選び、上限日数を超えない。
4. 送信 → 承認待ち。

**手順 — 確認**

- 一覧で状態（承認待ち / 承認 / 却下）を確認。
- 承認待ちは種別により編集・削除 / 取消ができることが多い。

**期待される結果:** 一覧に申請が表示され、承認者が処理できる。

**困ったとき**

- 送信できない → 日付・種別など必須項目を確認。
- 慶弔の日数超過 → 種別変更または期間短縮。
