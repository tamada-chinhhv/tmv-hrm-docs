# 勤務時間記録（出退勤）

**いつ使うか:** 勤務日ごとに、出社時と退社時（会社の規則による）。

**手順**

1. **勤怠・休暇** → **勤務時間記録**。
2. 出社時に**出社**を、退社時に**退社**をタップします。
3. **ウェブ版**: ブラウザに位置情報（GPS）へのアクセスを許可してください。
4. **モバイル版**: 拠点がWiFi認証を使用している場合、記録前に会社WiFiに接続してください。

**期待される結果:** 出社・退社時刻が記録され、当日の勤怠記録に表示されます。

## 月間カレンダーの勤怠ステータス

ダッシュボードの月間カレンダーには、出退勤時刻と各日の**ステータス**が表示されます。

| ステータス | 意味 |
|---|---|
| **出勤**（WORK） | 通常どおり出退勤を記録 |
| **遅刻・早退**（LATE_EARLY） | 遅刻または早退（申請あり） |
| **週末**（WEEKEND） | 土曜・日曜 |
| **祝日**（HOLIDAY） | 会社休日または祝日 |
| **休暇**（LEAVE） | 承認済みの休暇 |
| **欠勤**（ABSENT） | 出退勤の記録なし |
| **出社記録忘れ**（FORGOT_CLOCK_IN） | 勤務していたが出社記録がないとシステムが検知 |
| **ダッシュ（-）** | 未来の日付、またはその日の在籍情報がシステムにない |

色分けで素早く確認できます: **緑** = 通常勤務、**青** = 休み・週末、**黄** = 遅刻・早退・半日、**赤** = 欠勤または要確認。

### ダッシュ（-）が表示される日

ダッシュ（-）は、その日にあなたが在籍中の従業員として登録されていないことを意味します。

- 入社日より前、または退職後。
- 長期休職中。
- 未来の日付。
- 入社日・退職日のデータが欠落・誤っている場合。

**実際に勤務していた日**にダッシュが表示される場合は、人事に入社日・退職日の登録内容の確認を依頼してください。

## リモートワーク

- 当日の**リモートワーク**申請が承認済みの場合 → どこからでも記録でき、**GPS・会社WiFiは不要**です。
- 承認がない場合 → オフィスで記録する必要があります。在宅勤務が必要な場合は、事前にリモートワーク申請を行ってください。

**困ったとき**

- 「オフィスエリア外」と表示される → 拠点の範囲内に移動する、位置情報をオンにして精度を確認する、または正しい会社WiFiに接続してください。
- モバイルで記録できない → **会社WiFi**への接続、端末の**位置情報**設定、アプリへの位置情報の許可を確認してください。解決しない場合は、ウェブ版で記録するか、IT担当にご相談ください。
- 出社・退社の片方を記録し忘れた → 上司または人事に修正を依頼するか、会社の規則に従って修正申請を作成し、実際の出社・退社時刻を記載してください。
- 記録したのに表示されない → 少し待ってからページを再読み込みしてください。ログアウト・再ログインも有効です。解決しない場合はIT担当にご連絡ください。

**ヒント:** 出社したらすぐに記録し、退社前に忘れず記録する。アプリに位置情報の権限を許可する。記録の不具合は早めに報告する（月末まで溜めない）。
