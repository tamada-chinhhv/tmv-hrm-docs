# プロフィールとアバター

**いつ使うか:** 個人情報の確認・更新、プロフィール写真（アバター）の変更、アカウント設定の調整。

**手順 — プロフィールを開く**

1. 画面右上の**名前またはアバター**をクリックします。
2. **アカウント**を選択します。
3. 各タブで情報を確認・編集します。

## アバター（プロフィール写真）

アバターは、申請、コメント、従業員一覧など、システム全体であなたの名前の横に表示されます。

- **写真をアップロード済み** → 丸い枠内に写真が表示されます。
- **写真がない場合** → 色付きの背景に**名前のイニシャル**が表示されます（色はランダムに割り当て）。例: 「Ngô Linh」→ **NL**、一語の名前「Madonna」→ **M**、三語の名前 → 3文字。

**手順 — 写真を変更する**

1. **アカウント**で現在のアバターをクリック → **写真をアップロード / アバターを変更**を選択します。
2. 端末から写真を選択: **JPG / PNG**、**5 MB未満**。顔がはっきり分かるビジネス向けの写真を推奨します。
3. 丸い枠に収まらない場合は、**ドラッグ・ズーム**で顔を中央に調整 → **保存**。
4. イニシャル表示に戻したい場合は、**写真を削除**を選択して確認します。

## 個人情報

- **自分で編集可能:** メールアドレス、電話番号、アバター。
- **編集不可（会社・人事が管理）:** 氏名、従業員ID、部門、役職、入社日。変更が必要な場合（改名など）は人事にご相談ください。

## アカウント設定

**アカウント**の**設定**タブで以下を変更できます。

- **外観:** ライト / ダークテーマ、テーマカラー、フォントサイズ。
- **言語:** 表示言語の切り替え（利用可能な言語から選択）。
- **通知:** メール通知のオン / オフ、通知頻度。
- **セキュリティ:** パスワード変更、二要素認証（利用可能な場合）。

**ドキュメント**タブ（利用可能な場合）: 個人のドキュメントを確認・追加できます。

## あなたの情報は誰に見える?

- 氏名、アバター、部門・役職は、同僚・上司・人事に表示されます（申請やコメントの横、社内ディレクトリなど）。
- 実際の写真を載せるかイニシャルのままにするかは自分で選べます。電話番号は任意です。

**期待される結果:** プロフィールが更新され、写真またはイニシャルが名前の横に正しく表示されます。

**困ったとき**

- 写真をアップロードできない → 形式（JPG / PNG）、サイズ（5 MB未満）、選択後に**保存**を押したかを確認してください。解決しない場合は別のブラウザを試すか、キャッシュを削除、またはIT担当にご相談ください。
- 写真の切り抜きがおかしい → 写真を削除して再アップロードし、丸枠内で位置を調整し直してください。
- イニシャルが間違っている → プロフィールの氏名を確認してください。氏名が誤っている場合は人事に修正を依頼してください。
- 同僚がイニシャル表示のまま → 正常です。写真を未登録か、削除しただけです。

**ヒント:** 顔が分かる明るい写真を使うと、同僚に覚えてもらいやすくなります。メールアドレスと電話番号は常に最新に保ちましょう。
