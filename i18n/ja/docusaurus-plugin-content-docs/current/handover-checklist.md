# 引き渡しチェックリスト

- [ ] 初期アカウント一覧（ユーザー名、ロール）

- [ ] 打刻ガイド（Web: GPS、モバイル利用時: WiFi/BSSID）と `/sysConfig/locations` の拠点設定
