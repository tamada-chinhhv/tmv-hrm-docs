# 休暇の設定と管理

**いつ使うか:** 休暇の仕組みを会社の人事ポリシーに合わせて設定するとき: 休暇残数、無給休暇のルール、休暇種別とフィルター。

## 休暇残数（リーブバランス）の仕組み

休暇残数は、各従業員の休暇の「口座」のようなものです。会社が毎年休暇を**付与**し、従業員が取得時に**消費**し、残った分が**残数**です。

システムは正確に計算するため、休暇残数を**分単位**で管理します。

- 標準的な1営業日 = 480分（8時間 × 60）。
- 会社の設定に応じて**日数**または**分**で表示されます。

**例:** 有給10日 = 4,800分。1日取得 → 480分を差し引き。2時間取得 → 120分を差し引き。残り4,200分 = 8.75日。

**勤務時間の長さが異なる場合:** 会社によって1日8時間（480分）、6時間（360分）、10時間（600分）などがあります。システムは **システム設定** → **勤務シフト** の**勤務単位時間**に基づいて自動換算するため、この値が正しいことを確認してください。勤務単位を変更した場合、**それ以降**の換算に新しい値が使われ、既存の残数はそのまま維持されます。

## 休暇残数の手動調整（オーバーライド）

通常、従業員は残数を超えて休暇を取れません。人事は特別な状況に対応するため、残数を**手動調整**できます: 年度途中入社ですぐ病気休暇が必要、前借り（マイナス残数）を認めるポリシー、計算誤りの修正、特別対応など。

**手順**

1. **人事管理** → **従業員** → 対象の従業員を選択します。
2. **休暇残数**タブ → **残数を調整**をクリックします。
3. 休暇種別を選び、**調整量**を入力します（加算はプラス、減算はマイナス）。
4. 監査のため**理由**を記入 → **保存**。

残数は即時更新され、システム履歴に記録されます。注意: 調整は以降のすべての休暇申請に影響します。誤って入力した場合は、新しい調整で修正してください。

## 無給休暇（遅刻・早退）

無給休暇とは、**休暇残数を消費せずに**取る休みです（その時間分の給与は支払われません）。従業員の残数がない場合や、柔軟な勤務を認めるポリシーの場合に、主に**遅刻・早退**の申請で使われます。

従業員が遅刻・早退を申請する際、2つの選択肢があります: **残数から差し引く**（通常）または**無給として計上する**（残数はそのまま）。

**機能を有効にする:**

1. **システム設定** → **休暇設定**。
2. **遅刻・早退の無給休暇を許可**をオンにします。
3. 従業員が遅刻・早退を申請する際に、この選択肢が表示されるようになります。

注意: 無給休暇も記録として**システムに残り**、**上長の承認**が必要です。有効にする前に会社のポリシーをご確認ください。

## 休暇種別とフィルター

**休暇種別の設定:**

1. **システム設定** → **休暇種別**。
2. 種別を追加・編集します。各種別には**表示名**（例:「年次有給」）、**コード**（例: VACATION）、**有給かどうか**、**残数が必要かどうか**があります。
3. 保存します。

**種別でのフィルター:** 休暇申請の一覧（休暇承認 / 休暇申請）で**休暇種別フィルター**を使うと、特定の種別だけを表示できます。例: 直近3か月の病気休暇だけを表示して傾向を把握する、有給だけを表示して夏季の人員計画を立てる、など。フィルターは、自分の申請一覧、承認画面、休暇レポート、従業員別の休暇履歴で利用できます。

**期待される結果:** 従業員の申請フォームに正しい休暇種別が表示され、人事が残数を管理し、種別ごとの取得状況を把握できます。

**活用例**

- **年度途中入社の従業員:** **従業員** → 対象者 → **休暇残数** → +5日（2,400分）を調整。理由:「年度途中入社の按分付与」。
- **残数ゼロだが通院で3時間必要:** 従業員が申請 → 人事・上長が**無給**として承認 → 3時間は記録されるが残数は減りません。

**困ったとき**

- 残数ゼロの従業員が申請できない → その休暇種別が残数を必須にしています。マイナス残数を認める場合は、種別設定の**残数必須**をオフにしてください。
- 分ではなく日数で表示したい → 会社の表示設定によります。システム管理者に**システム設定**の表示単位の確認を依頼してください。
- 無給で承認したのに残数が減っている → 承認時に「無給」が選択されたか、種別の設定が正しいかを確認してください。誤っていた場合は残数を手動調整してください。
- 全従業員の残数を一覧したい → **人事管理** → **休暇残数レポート**（利用可能な場合）をご覧ください。
