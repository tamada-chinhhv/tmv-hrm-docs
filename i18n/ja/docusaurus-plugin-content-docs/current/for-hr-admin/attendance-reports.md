# 部門別勤怠レポート

**いつ使うか:** **本日**の勤怠状況を部門ごとに素早く確認したいとき: 誰が出勤しているか、休暇中か、遅刻か、欠勤か。

## レポートに表示される内容

各部門にサマリーカードが表示され、従業員の打刻に合わせて**リアルタイム**に更新されます。

| 項目 | 意味 |
|---|---|
| **合計** | 部門の従業員数 |
| **出勤** | 本日打刻済みの従業員 |
| **休暇** | 承認済みの休暇中（有給、病気休暇など） |
| **遅刻** | シフト開始後に打刻した従業員 |
| **欠勤** | 打刻がなく、休暇申請もない従業員 |
| **出勤率** | 出勤または承認済み休暇の従業員の割合 |

色分け: **緑** = 定刻出勤、**黄 / オレンジ** = 遅刻、**青** = 承認済み休暇、**赤** = 欠勤、**グレー** = シフト未割り当て（新入社員など）。

**出勤率の計算:** （出勤 + 休暇）÷ 合計 × 100。例: 部門20名、18名出勤、1名承認済み休暇、1名欠勤 → （18 + 1）÷ 20 = **95%**。

**手順**

1. **勤怠・休暇** → **勤怠確認**。
2. **部門別勤怠**セクションで各カードを確認し、欠勤数（赤い数字）に注目します。
3. 部門カードをクリックすると、従業員ごとの詳細（氏名、役職、出退勤時刻、ステータス）が表示されます。
4. 欠勤が多い部門は、欠勤とされた従業員を確認し、未承認の休暇申請がないか確かめたうえで、本人に連絡して状況を確認します。

**期待される結果:** 当日の勤怠状況を部門横断で把握でき、予定外の欠勤を早期に発見して対応できます。

## 効果的な使い方

- **朝のうちに確認** — 無断欠勤を早めに見つけて連絡できます。
- **傾向を観察** — 週次で確認し、パターン（月曜の欠勤、特定曜日の遅刻など）を見つけてチームリーダーと相談します。
- **休暇と欠勤を区別** — 青い数字は計画的な休み（承認済み）、赤い数字は予定外の欠勤でフォローが必要です。
- **休暇申請と突き合わせ** — 欠勤扱いの従業員が、承認待ちの申請を出している場合があります。
- **マネージャーと共有** — 各部門長が自チームの状況把握に活用できます。

**困ったとき**

- 承認済み休暇があるのに出勤率が低い → 承認済み休暇は出勤率に含まれます。それでも低い場合は**無断欠勤**がいる可能性があります。赤い数字を確認してください。
- 過去のデータを見たい → このレポートは当日分です。履歴は**勤怠確認**で日付範囲を絞って確認してください。
- リモート勤務者が欠勤扱いになる → リモートワーク申請が承認済みか確認してください。必要に応じて、規則に従い勤怠を手動調整します。
- 数値が更新されない → 打刻後数秒で反映されます。必要に応じてページを再読み込みしてください。
