# 残業管理（一括編集）

**いつ使うか:** **承認済み**の残業バッチを、再承認なしで直接修正・一括更新する必要がある場合（権限を持つ人事担当者向け）。

## 残業の一括編集とは?

通常、残業申請は部門長と取締役の承認を経て、承認後は変更できません。一括編集機能を使うと、特別な権限を持つ人事担当者が承認済みレコードを**直接編集**できます。次のような場合に便利です。

- **誤りの修正** — 時間、日付、従業員情報の間違いを直す。
- **一括更新** — 複数の残業バッチを1件ずつではなくまとめて更新する。
- **承認済みレコードの調整** — 再承認の手続きなしで内容を変更する。
- **特別対応** — 経営側からの急な変更依頼に対応する。

## 誰が使える?

**OT_BATCH_EDIT_ANY** 権限を持つユーザーのみ使用できます。

権限の確認: **システム設定** → **権限設定** → 自分のロールまたはユーザーを探し、権限一覧に **OT_BATCH_EDIT_ANY** があるか確認します。ない場合はシステム管理者に付与を依頼してください。詳細は[権限設定](./permissions.md)をご覧ください。

## 編集の手順

1. **勤怠・休暇** → **残業管理** — すべての残業バッチの一覧が表示されます。
2. 編集したいバッチを探して（日付・部門・従業員名で検索可能）開きます。
3. 編集できる項目:
   - **勤務日** — 残業を実施した日付の変更。
   - **時間** — 従業員ごとの開始・終了時刻の修正（時間数は自動再計算）。
   - **シフト種別** — 通常日 / 祝日 / 休日残業の切り替え。
   - **作業内容・備考** — 理由や作業種別の更新。
   - **従業員の追加・削除**。
4. 内容をよく確認して**保存**します。変更は**即時**反映され、再承認は不要です。

## 通常の残業申請との違い

| | 通常の残業申請 | 一括編集 |
|---|---|---|
| **開始方法** | 新規作成 | 既存レコードを編集 |
| **承認** | 部門長・取締役の承認が必要 | 承認不要 |
| **実行者** | 従業員、マネージャー | OT_BATCH_EDIT_ANY を持つ人事 |
| **用途** | 新しい残業の申請 | 誤りの修正、調整 |
| **所要時間** | 承認待ちが発生 | 即時反映 |

**期待される結果:** 残業レコードが即時更新され、誰が何を変更したかが履歴に記録されます。

## 重要な注意点

- **編集者の責任** — 一括編集は承認を経ない最終決定です。慎重にご利用ください。
- **即時反映** — 保存前に内容を十分確認してください。
- **監査履歴** — すべての編集はシステム履歴に記録されます。
- **承認済みバッチのみ** — 「承認済み」状態のバッチだけ編集できます（下書きや却下済みは不可）。

**困ったとき**

- 編集ボタンが表示されない → バッチが**承認済み**状態か確認してください。下書き・承認待ちは、先に部門長・取締役の処理が必要です。
- OT_BATCH_EDIT_ANY があるのに編集できない → ページを再読み込みするか、ログアウト・再ログインしてください。
- 変更を元に戻したい → 取り消し機能はありません。履歴で元の値を確認し、手動で戻してください。
